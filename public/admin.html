Broadcasts send a notification to every user. Use them for network-wide announcements; sending cannot be recalled here, so send a correction if needed.

Broadcast Notification

This sends the title and message to every user across OpenVibe. Review the wording and destination before sending; there is no recall control here.

Notification title. The title everyone will see; required with no default. For example: Scheduled maintenance.
Notification message. The announcement body; required with no default. For example: We will be back at 18:00 UTC.
Notification icon. The default is the announcement emoji. Use one recognizable emoji, for example 📢.
How urgent is this? Normal is the default for routine news; High calls for attention, and Critical marks an urgent issue. Choose Critical only when everyone needs to know promptly.
Link to open. Optional destination when someone opens the notification; blank means no destination link. For example: https://openvibe.network.

This delivers the notification to all users. It cannot be recalled here; send a correction if needed.

Admins can send one global notification every 6 hours. Owners are exempt.
